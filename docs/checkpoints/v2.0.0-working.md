# v2.0.0 working checkpoint

This checkpoint preserves the installed ConnectPhone 2.0.0 (build 200) state
before the multi-device redesign begins.

## What is captured

- Full application source, including the fast saved-phone startup reconnect.
- Reconnect safety improvements that distinguish an unavailable ADB daemon
  from an empty device list and recover stale wireless transports carefully.
- A complete file-by-file SHA-256 manifest of the installed app bundle.
- Code-signing, PyInstaller, macOS, ADB, scrcpy, and Homebrew build metadata.
- The exact ad-hoc-signed `ConnectPhone.app` as the release asset
  `ConnectPhone-2.0.0-build200-working.app.zip`.

The checked-in `ConnectPhoneUI.py` was compared recursively with the raw
marshalled PyInstaller entry point. Its bytecode, constants, nested functions,
line tables, and exception tables are canonically equivalent. The comparison
tool and extracted entry point are preserved in the repository. Re-run the
comparison with:

```zsh
python3 scripts/verify_packaged_source.py \
  ConnectPhoneUI.py \
  metadata/checkpoints/v2.0.0-working/ConnectPhoneUI.marshalled
```

The release asset SHA-256 is recorded in
`metadata/checkpoints/v2.0.0-working/release-asset.sha256`.

## Restore the exact app

Download the release ZIP, then run:

```zsh
./scripts/restore-release.sh ~/Downloads/ConnectPhone-2.0.0-build200-working.app.zip
```

The restore script verifies the archive's code signature before installation,
backs up any existing `/Applications/ConnectPhone.app` into
`~/ConnectPhone-backups`, restores the checkpoint, and verifies it again.

To confirm that the currently installed bundle is exactly this checkpoint:

```zsh
./scripts/verify-installed-checkpoint.sh
```

## Restore source only

```zsh
git switch --detach v2.0.0-working
```

Use a new branch from the tag if you intend to edit it:

```zsh
git switch -c restore-v2.0.0-working v2.0.0-working
```
